1. Design Goals & System Boundaries

This system focuses on extracting market signals rather than generic chat summaries: identifying who is supplying/demanding what resource, prices, volumes, transaction commitments, and maintaining a strict provenance trail back to the source messages.

AuditableEvery signal retains source message IDs, user IDs, original raw price/volume strings, and an LLM-generated explanation.
ReplayableThe original data is an append-only JSONL stream. The pipeline can be fully re-run deterministically over the same data.
Uncertainty-AwareIf units, currencies, or resource types are missing, the system preserves the unknown state and lowers confidence rather than hallucinating precise values.
Model AgnosticIntegrates via standard OpenAI-compatible SDKs (e.g., OpenRouter), allowing seamless switching between Gemini, Claude, and GPT models.

4. Context Assembly Strategies

Context is the conversational unit required to understand a market signal. Instead of sending messages one by one (missing context) or all at once (high token cost, hallucination risk), messages are grouped dynamically.

StrategyRuleResult
1. Reply ThreadTrace explicit reply_to links to build a full thread (oldest to newest).Captures multi-party negotiation accurately.
2. Time WindowGroup messages from the same user and group within a 5-minute inactivity window.Captures self-corrections and split sentences.
3. StandaloneMessages with no replies and outside the time window.Processed individually.

5. Adversarial Scenarios & Exact Chat Examples

The pipeline is designed to handle messy, informal chat data. Below are the key scenarios handled and the exact chat logs representing them.

Scenario A: Self-Correction

Users often make typos and correct themselves in a subsequent message. Time-window context assembly groups these together so the LLM extracts only the final corrected value.

alice: Selling Claude API credits, 4.0 per unit, have about 500k.
alice: Typo sorry, meant 3.8 per unit not 4.0

Result: Extracts a single sell signal for Claude_API at price 3.8.

Scenario B: Missing Units & Slang

Informal markets use slang (e.g., "8-card", "below 4"). The normalization layer maps aliases to canonical entities, while the schema retains raw strings when parsing fails.

carol: Got 8-card A100s, spot, anyone interested?
bob: Still looking for 500k OpenAI credits, below 4 if possible.

Result: "A100s" maps to A100_GPU. "below 4" is stored in raw_price_str.

Scenario C: Broker Spam (Deduplication)

Brokers often spam the exact same message across multiple channels. The normalization layer calculates a content hash and suppresses duplicates within a time window.

broker_x: Discounted Midjourney annual subs, $150 each, limited stock. (grp_ai_trading)
broker_x: Discounted Midjourney annual subs, $150 each, limited stock. (grp_secondary)
broker_y: Discounted Midjourney annual subs, $150 each, limited stock. (grp_resellers)

Result: Only the first message generates a market signal. Subsequent identical hashes are suppressed.

Scenario D: Historical Chatter & Complaints

Complaints about quotas or reminiscing about past prices should not affect current market depth or median price calculations.

dave: Remember when OpenAI credits were going for 2.0? Crazy times lol.
frank: AWS quotas are so annoying this week honestly.

Result: Intent classified as observation_past and irrelevant. Ignored during aggregation.

Scenario E: Bundled Offers

A single message containing multiple distinct resources and prices. The schema enforces a List[MarketSignal] output to capture all entities.

grace: Got 2 AWS $100k accounts at 30% off, and throwing in a GCP $50k account for 25% off.

Result: Generates two signals: one for AWS_Compute and one for GCP_Compute.

Scenario F: Multi-party Transaction Threads

Replies form a thread where the final commitment relies on the resource mentioned at the root of the thread. Reply-chain assembly handles this seamlessly.

henry: Need $120 OpenAI accounts, anyone have stock?
ivan: I have 5. Standard rate? (replying to henry)
henry: Deal, PM me. (replying to ivan)

Result: Extracts a transaction_completed signal for OpenAI_Credits at price 120 with volume 5.

6. UI Reports & Aggregation

Market Depth (Aggregation Layer)

Prices in informal markets often contain extreme outliers (e.g., misquotes). We use confidence-weighted median prices rather than arithmetic means to ensure robustness.

MetricCalculation Method
Median PriceCalculated from active buy and sell signals. Heavily weights high-confidence signals.
Price RangeMin and Max prices within the active signal window.
Independent SignalsTotal number of unique signals contributing to the resource trend.

Extracted Signals Feed

The raw signal feed displays the LLM's direct output, including the original strings (raw_price_str), the confidence score, the AI's explanation, and the exact source message IDs for full auditability.
